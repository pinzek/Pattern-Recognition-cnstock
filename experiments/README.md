# Experiment Archive

This folder documents the project evolution from V1 to V4. These materials are included for research presentation and workflow reproducibility, while raw market data, licensed datasets, cache files, and large intermediate files are excluded.

## Version Overview

| Version | Focus | Description |
|---|---|---|
| V1 | HMM market state recognition | Identified market regimes using Gaussian HMM and market-level features. |
| V2 | Supervised stock return prediction | Tested traditional machine learning models for A-share cross-sectional return prediction. |
| V3 | HMM state features | Tested whether HMM state probabilities add predictive value in supervised models. |
| V4 | HMM-informed Transformer | Compared multi-scale Transformer and HMM-informed Transformer using historical windows. |

## Data Policy

Raw data and large intermediate outputs are not included. Only notebooks, figures, reports, and high-level summaries are provided.
